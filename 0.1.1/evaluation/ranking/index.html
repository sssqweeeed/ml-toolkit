    Ranking¶

    Rank rows by their predicted outcome and measure how much observed outcome falls within a limited review or service capacity. Gains and Lift require finite, nonnegative targets and a positive weighted observed total. They use confirmed outcomes; PU capture has a different meaning.

    Prepare predictions¶

    Run from the installed repository checkout after the data preparation. The example fits recorded 2011 hours and evaluates 2012 hours. The target is rentals per hour and each row has unit exposure, so capacity is a fraction of hours. The reports rank only the 2012 test hours.

    from pathlib import Path

import numpy as np
import polars as pl

from examples.evaluation_data import fit_bike_evaluation
from ml_toolkit.config import FigureConfig

example = fit_bike_evaluation(classification=False)
data, prediction, split = example.data, example.prediction, example.split
train, test = example.train, example.test
train_prediction = prediction[: len(train)]
test_prediction = prediction[len(train) :]
output = Path("figures")
figure = FigureConfig(dpi=150)
print(f"2011 train hours: {len(train)}; 2012 test hours: {len(test)}")

    2011 train hours: 8645; 2012 test hours: 8734

    Gains and lift reports¶

    Use this list as prediction_evaluators=reports in training. These calls produce the same report files from existing predictions:

    from ml_toolkit.evaluation import Gains, Lift

reports = [Gains(), Lift()]
for report in reports:
    files = report.write_artifacts(
        data=data,
        prediction=prediction,
        split=split,
        artifact_dir=output / report.name,
        figure=figure,
        features=None,
        n_bins=10,
    )
    print([path.relative_to(output).as_posix() for path in files])

    ['gains/test/gains.png']
['lift/test/lift.png']

    Gains¶

    The x-axis is cumulative exposure after sorting from highest to lowest score. The y-axis is the share of total observed × exposure captured. The diagonal shows uniform selection. A curve above it captures more outcome with the same capacity; the marked 10% point summarizes a common operating capacity.

    Lift¶

    Lift divides captured outcome share by the exposure share. A value of 2 means capturing twice the outcome expected from uniform selection at that capacity.

    Inspect the curves and selected capacities¶

    from ml_toolkit.metrics import ranking_metrics
from ml_toolkit.plots import ranking

ranked = ranking_metrics(
    test.y.to_numpy(), test_prediction, test.weight.to_numpy()
)
ranking.gains_curve(ranked, output / "direct-gains.png", figure=figure)
ranking.lift_curve(ranked, output / "direct-lift.png", figure=figure)
print(
    [
        (point.percent, round(point.gain, 3), round(point.lift, 3))
        for point in ranked.selected_points
    ]
)
selected = ranking_metrics(
    test.y.to_numpy(),
    test_prediction,
    test.weight.to_numpy(),
    selected_percents=(10.0, 20.0),
)
print(
    [
        (point.percent, round(point.gain, 3), round(point.lift, 3))
        for point in selected.selected_points
    ]
)

    [(10.0, 0.277, 2.767)]
[(10.0, 0.277, 2.767), (20.0, 0.473, 2.367)]

    ranking_metrics returns cumulative arrays and selected points; plotting calls return None. Selected points interpolate at the requested exposure fraction. Zero-exposure rows are omitted and tied predictions retain input order. The evaluator classes use the default 10% point; direct plotting accepts any RankingMetrics result, including other selected capacities.

    API reference¶

    Gains dataclass ¶

    Gains(*, name: str = 'gains')

    Bases: PredictionEvaluator

    Plot captured observed outcome against held-out exposure capacity.

    Parameters:

    Name Type Description Default
    name str

    Unique report name and artifact namespace.

    		 'gains'
    Notes

    Ranks validation or test rows by descending prediction. Pool weights supply exposure; targets must be nonnegative with positive weighted total. The curve shows cumulative target * weight share, including the default 10% capacity point. Saves <split>/gains.<format>.

    Lift dataclass ¶

    Lift(*, name: str = 'lift')

    Bases: PredictionEvaluator

    Plot held-out outcome capture relative to uniform selection.

    Parameters:

    Name Type Description Default
    name str

    Unique report name and artifact namespace.

    		 'lift'
    Notes

    Lift divides captured weighted outcome share by exposure share after ranking by prediction. Uses validation or test rows and the default 10% capacity point. Targets must be nonnegative with positive weighted total. Saves <split>/lift.<format>.
