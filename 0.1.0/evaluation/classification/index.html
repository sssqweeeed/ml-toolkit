    Classification¶

    Inspect a binary classifier's probability thresholds and calibration on held-out observations. The target must contain confirmed 0/1 labels; predictions must be finite positive-class probabilities in [0, 1]. These reports do not apply to unverified PU labels.

    Prepare predictions¶

    Run from the installed repository checkout after the data preparation. The example fits recorded 2011 hours and evaluates 2012 hours. A positive hour means at least 200 rentals. All curves below use only the 2012 test probabilities; the model never fits those rows.

    from pathlib import Path

import numpy as np
import polars as pl

from examples.evaluation_data import fit_bike_evaluation
from ml_toolkit.config import FigureConfig

example = fit_bike_evaluation(classification=True)
data, prediction, split = example.data, example.prediction, example.split
train, test = example.train, example.test
train_prediction = prediction[: len(train)]
test_prediction = prediction[len(train) :]
output = Path("figures")
figure = FigureConfig(dpi=150)
print(f"2011 train hours: {len(train)}; 2012 test hours: {len(test)}")

    2011 train hours: 8645; 2012 test hours: 8734

    Reports in training¶

    Use the following list as prediction_evaluators=reports in the training call. To inspect the exact reports without a tracking server, call their artifact methods on the prepared inputs:

    from ml_toolkit.evaluation import PrecisionRecall, F1Threshold, Calibration

reports = [PrecisionRecall(), F1Threshold(), Calibration()]
for report in reports:
    files = report.write_artifacts(
        data=data,
        prediction=prediction,
        split=split,
        artifact_dir=output / report.name,
        figure=figure,
        features=None,
        n_bins=10,
    )
    print(report.name, [path.relative_to(output).as_posix() for path in files])

    precision_recall ['precision_recall/test/precision_recall.png']
f1_threshold ['f1_threshold/test/f1_threshold.png']
calibration ['calibration/test/calibration.png']

    Precision and recall¶

    The x-axis is recall: the fraction of positive rows captured. The y-axis is precision: the positive fraction of flagged rows. Each curve point corresponds to a probability threshold. The dashed line shows positive prevalence, and the marked point identifies the best F1 on this sample. Tied scores enter together, with prediction >= threshold defining a positive prediction.

    PrecisionRecall(max_curve_points=1000) limits rendered points, preserving the full threshold table from the direct function. Draw the same figure directly:

    from ml_toolkit.plots import classification

observed, probabilities = test.y.to_numpy(), test_prediction
precision_recall_table = classification.precision_recall(
    observed,
    probabilities,
    output / "direct-precision-recall.png",
    weight=test.weight.to_numpy(),
    figure=figure,
)
curve = classification.binary_curves(
    observed, probabilities, weight=test.weight.to_numpy()
)
print(
    curve.iloc[np.linspace(0, len(curve) - 1, 6, dtype=int)]
    .round(3)
    .to_string(index=False)
)
assert curve.equals(precision_recall_table)

    F1 by threshold¶

    F1 is the harmonic mean of precision and recall. This plot identifies threshold tradeoffs on the supplied sample; adding the evaluator does not change the model's decision threshold. Select a threshold using validation rather than optimizing it on the test figure.

    f1_table = classification.f1_threshold(
    observed,
    probabilities,
    output / "direct-f1-threshold.png",
    weight=test.weight.to_numpy(),
    figure=figure,
)
assert f1_table.equals(curve)

    F1Threshold(max_curve_points=1000) has the same rendering limit and full-table return behavior as precision/recall.

    Calibration¶

    The calibration curve compares mean predicted probability with the observed positive rate within score quantiles. The diagonal represents perfect calibration. The accompanying histogram shows where prediction mass lies. Here most points lie above the diagonal: the model underestimates the positive rate in those test-score bins.

    calibration_table = classification.calibration(
    observed,
    probabilities,
    output / "direct-calibration.png",
    weight=test.weight.to_numpy(),
    n_bins=10,
    histogram_bins=30,
    figure=figure,
)
print(calibration_table.round(3).to_string(index=False))

     bin  observed_rate  predicted_rate  count  weight_sum

   1          0.002           0.011    873       873.0

    Calibration(n_bins=10, histogram_bins=30) controls calibration quantiles and histogram bins independently. Its n_bins is distinct from shared feature-level binning in ReportingConfig.

    Precision, recall, F1, prevalence, AP, calibration means and histograms use row weights. Zero-weight rows are ignored. Calibration boundaries remain unweighted quantiles of positive-weight rows; count counts those rows and weight_sum reports their total weight. The direct calibration call returns this full table.

    Use probabilities from another dataset¶

    Direct functions also accept non-temporal data. The original handwritten digits example uses scikit-learn's 1,797 images, with digits 0–4 as class 0 and 5–9 as class 1. A fixed stratified split trains on 1,078 images and evaluates the other 719; no artificial dates or Pool are needed to calculate its curve.

    from examples.gallery_data import load_gallery_data

digits, _ = load_gallery_data(download_if_missing=False)
digits_curve = classification.binary_curves(
    digits.observed, digits.probabilities
)
print(
    f"Training images: {len(digits.train_indices)}; held-out images: {len(digits.observed)}"
)
print(
    digits_curve.iloc[np.linspace(0, len(digits_curve) - 1, 6, dtype=int)]
    .round(3)
    .to_string(index=False)
)

    classification ¶

    Binary classification precision, recall, F1, and calibration plots.

    binary_curves ¶

    binary_curves(
    observed: ArrayLike,
    probabilities: ArrayLike,
    *,
    weight: ArrayLike | None = None
) -> pd.DataFrame

    Compute weighted binary scores at each distinct probability threshold.

    Parameters:

    Name Type Description Default
    observed array-like of shape (n_samples,)

    Nonempty binary ground-truth labels, containing only 0 and 1.

    		 required
    probabilities array-like of shape (n_samples,)

    Finite positive-class probabilities in [0, 1], aligned with labels.

    		 required
    weight array-like of shape (n_samples,) or None

    Nonnegative finite sample weights with positive total; None uses ones. Zero-weight rows do not influence the calculations.

    		 None

    Returns:

    Type Description
    DataFrame

    Columns threshold, precision, recall, and f1 at distinct descending score thresholds; all tied scores enter together.

    Raises:

    Type Description
    PlotError

    Inputs are empty, non-finite, misaligned, or outside the label/probability domain.
    Notes

    Labels are predicted with probability >= threshold. Recall and F1 are zero when there are no positives. Requires binary ground truth, not PU labels.

    Examples:

    This small calculation shows the precision/recall tradeoff: lowering the threshold from 0.9 to 0.6 finds the second positive and one false positive.

    >>> from ml_toolkit.plots.classification import binary_curves
>>> curve = binary_curves([1, 0, 1, 0], [0.9, 0.8, 0.6, 0.2])
>>> print(curve.iloc[[0, 2]].round(3).to_string(index=False))
 threshold  precision  recall    f1
       0.9      1.000     0.5 0.667
       0.6      0.667     1.0 0.800
