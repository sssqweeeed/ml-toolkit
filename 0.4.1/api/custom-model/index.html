    Build a model adapter¶

    Implement Model when your project needs its own fitting or prediction policy. The example below trains a CatBoost RMSE model in thousands of hourly bike rentals and returns predictions in rentals per hour. It composes a new adapter around a built-in model and preserves that transformation when logging to MLflow.

    The complete runnable files are examples/custom_model.py and examples/custom_model_serving.py in the repository checkout. They use the built-in Pool to hold prepared data.

    Run the complete example¶

    From the installed repository checkout, download the source data once with python -m examples.prepare_data, then run:

    python -m examples.custom_model

    Or run it from Python:

    from examples.custom_model import demo

demo()

    native predictions (thousands): [0.1959, 0.1918, 0.1883, 0.2361, 0.2308]
observed rentals: [283.0, 253.0, 261.0, 306.0, 445.0]
predicted rentals: [195.9, 191.8, 188.3, 236.1, 230.8]

test MAE: 91.174
serving predictions match: True

    The example uses all 17,379 original UCI Bike Sharing hours from 2011–2012, with weather/calendar features, recorded rental counts and timestamps, and unit weights. It reserves the latest 20% for test and validates on the last 25% of the remaining rows. The normal workflow refits on non-test observations; the example logs that exact final adapter, reloads it, and checks prediction equality on the untouched test tail. The displayed test MAE and serving predictions therefore describe the same fitted adapter. MLflow uses a temporary local database and artifact directory that are removed after the check. No remote tracking service or registry is required.

    Implement the training contract¶

    Explicit inheritance from Model is unnecessary. A factory accepts a ModelParams dictionary and returns a fresh object with these operations:

    Operation What the example does Contract to preserve
    fit(train, validation) Divides both targets by the fixed scale; delegates fitting Preserve row metadata, use validation only for selection, return the fitted adapter
    predict_pool(data) Multiplies native predictions back by the scale Return one finite prediction per row in the metric's target units
    native_model Exposes the fitted CatBoostRegressor Supply the native backend used by supported diagnostics
    best_iteration Delegates the validation-selected iteration Return a zero-based index or None
    feature_importances(data) Delegates native feature ranking Return one finite value for every current feature name
    get_refit_params() Reuses the selected iteration budget and disables early stopping Return copied constructor settings, without learned state
    log(sample, config=...) Saves native weights, scale settings, and serving source Preserve the adapter's complete prediction behavior

    To support PSI baseline packaging, implement the optional keyword argument extra_artifacts: Mapping[str, str] | None = None in log. Merge those artifacts with the adapter's native files and pass them to mlflow.pyfunc.log_model before registration. Reject duplicate artifact names rather than overwriting model state. The complete example demonstrates this contract. Existing workflow calls omit this keyword when no baseline is attached; custom adapters enabling PSI packaging must accept and preserve it.

    fit uses Pool.with_target, so timestamps, weights, IDs, and categorical metadata stay aligned. The scale is fixed project configuration; it is never estimated from the validation or test rows. The factory supplies that same scale to every fresh adapter. Selection and tuning therefore compare predictions in the original target units.

    Complete adapter and factory source 
    from __future__ import annotations

from collections.abc import Mapping

from ml_toolkit.training import Holdout

import json
from importlib.metadata import version
from math import isfinite
from pathlib import Path
from tempfile import TemporaryDirectory
from typing import Self

import catboost
import mlflow
import numpy as np
import polars as pl
from mlflow.models import infer_signature
from mlflow.models.model import ModelInfo

from ml_toolkit import Pool, train_model
from ml_toolkit.config import TrackingConfig, TrainingConfig
from ml_toolkit.models import CatBoostRegressionModel
from ml_toolkit.tracking.model_artifacts import merge_artifacts
from ml_toolkit.types import FloatArray, ModelParams


class TargetScaledRegressor:
    """Fit a CatBoost RMSE regressor in scaled target units.

    Parameters
    ----------
    params : ModelParams
        Native CatBoost RMSE settings, copied by the wrapped adapter.
    target_scale : float, default 1000.0
        Positive finite conversion factor. Training divides targets by this
        factor; prediction multiplies outputs back into original units.

    Notes
    -----
    The factory must reuse the same target_scale for validation and final
    fitting. Native SHAP contributions describe scaled targets. Logged serving
    predictions retain the complete inverse transformation.
    """

    def __init__(self, params: ModelParams, *, target_scale: float = 1000.0) -> None:
        if not isfinite(target_scale) or target_scale <= 0:
            raise ValueError("target_scale must be finite and positive")
        self.target_scale = target_scale
        self._inner = CatBoostRegressionModel(params)

    @property
    def native_model(self) -> catboost.CatBoostRegressor:
        """Return the fitted backend, whose outputs are in scaled target units."""
        return self._inner.native_model

    @property
    def best_iteration(self) -> int | None:
        """Return the zero-based iteration chosen on validation, when available."""
        return self._inner.best_iteration

    def fit(self, train: Pool, validation: Pool | None = None) -> Self:
        """Fit on transformed targets while preserving aligned row metadata.

        Parameters
        ----------
        train : Pool
            Aligned training rows with targets in original units.
        validation : Pool or None, default None
            Optional holdout rows transformed using the same fixed scale.

        Returns
        -------
        Self
            Fitted adapter.
        """
        scaled_train = train.with_target(train.y.cast(pl.Float64) / self.target_scale)
        scaled_validation = (
            None
            if validation is None
            else validation.with_target(
                validation.y.cast(pl.Float64) / self.target_scale
            )
        )
        self._inner.fit(scaled_train, scaled_validation)
        return self

    def predict_pool(self, data: Pool) -> FloatArray:
        """Return one prediction per row in original target units.

        Parameters
        ----------
        data : Pool
            Rows containing the fitted feature columns.

        Returns
        -------
        FloatArray
            Predictions of shape (n_samples,) in original units.
        """
        return self._inner.predict_pool(data) * self.target_scale

    def feature_importances(self, data: Pool) -> dict[str, float]:
        """Return the wrapped backend's importance for each current feature.

        Parameters
        ----------
        data : Pool
            Current feature subset in fitted order.

        Returns
        -------
        dict[str, float]
            Importance for every supplied feature, suitable for importance_ranker.
        """
        return self._inner.feature_importances(data)

    def get_refit_params(self) -> ModelParams:
        """Return fresh constructor settings with the fitted iteration budget.

        Returns
        -------
        ModelParams
            Copied backend parameters with early stopping disabled. The factory
            supplies target_scale separately; learned state is never reused.
        """
        return self._inner.get_refit_params()

    def log(
        self,
        sample: Pool,
        *,
        config: TrackingConfig | None = None,
        extra_artifacts: Mapping[str, str] | None = None,
    ) -> ModelInfo:
        """Log native artifacts and an entrypoint that reverses target scaling.

        Parameters
        ----------
        sample : Pool
            Representative serving rows in fitted feature order.
        config : TrackingConfig or None, default None
            Artifact name, registry, example size, and optional environment file.

        extra_artifacts : Mapping[str, str] or None, default None
            Additional files or directories bundled with the model. Names must
            not conflict with the adapter's own artifacts.

        Returns
        -------
        ModelInfo
            Logged complete adapter's serving URI.

        Notes
        -----
        Call inside an active MLflow run. The serving entrypoint uses CatBoost,
        pandas, NumPy, and MLflow; it does not import the training example.
        """
        config = TrackingConfig() if config is None else config
        frame = sample.to_model_input(
            n_rows=config.input_example_rows, categorical_as_strings=True
        )
        frame = frame.loc[:, self._inner.feature_names]
        prediction = self._inner.predict_frame(frame) * self.target_scale
        with TemporaryDirectory(prefix="target-scaled-model-") as directory:
            root = Path(directory)
            model_path = root / "model.cbm"
            self.native_model.save_model(str(model_path))
            state_path = root / "settings.json"
            state_path.write_text(
                json.dumps(
                    {
                        "target_scale": self.target_scale,
                        "feature_names": self._inner.feature_names,
                        "cat_features": self._inner.cat_features,
                    }
                ),
                encoding="utf-8",
            )
            return mlflow.pyfunc.log_model(
                name=config.model_name,
                python_model=str(Path(__file__).with_name("custom_model_serving.py")),
                artifacts=merge_artifacts(
                    {"model": str(model_path), "settings": str(state_path)},
                    extra_artifacts,
                ),
                signature=infer_signature(frame, prediction),
                input_example=frame,
                params={},
                metadata={"target_scale": self.target_scale},
                code_paths=[],
                registered_model_name=config.registered_model_name,
                conda_env=None if config.conda_env is None else str(config.conda_env),
                pip_requirements=(
                    [
                        f"{package}=={version(package)}"
                        for package in ("mlflow", "catboost", "numpy", "pandas")
                    ]
                    if config.conda_env is None
                    else None
                ),
            )


def model_factory(params: ModelParams) -> TargetScaledRegressor:
    """Create an independent adapter using the same project target scale.

    Parameters
    ----------
    params : ModelParams
        Backend settings for a fresh fit.

    Returns
    -------
    TargetScaledRegressor
        Unfitted adapter with a new inner CatBoost model.
    """
    return TargetScaledRegressor(params, target_scale=1000.0)

    The source uses the built-in regressor for CatBoost's categorical preparation, early stopping, feature importance, and refit policy. A custom implementation can perform those operations itself, provided it keeps the same contracts. Create new nested models and learned preprocessing objects in each factory call; do not close over a fitted estimator or reuse mutable learned state.

    Connect the factory to training¶

    The demo() function shows the complete call, including data preparation:

    Executable workflow source 
    from examples.custom_metric import weighted_mae


def demo() -> None:
    """Run deterministic validation, final fitting, and serving parity checks.

    Notes
    -----
    Uses cached UCI Bike Sharing observations and a temporary local MLflow
    store. Prepare the cache with python -m examples.prepare_data, then run
    python -m examples.custom_model. The model fitted without test rows is
    logged and checked on the untouched future test tail; artifacts are removed
    after the check.
    """
    from examples.gallery_data import load_bike_pool

    data = load_bike_pool(download_if_missing=False)
    splitter = Holdout(data, val_size=0.25, test_size=0.2)
    partition = splitter.get_test()
    assert partition.heldout is not None
    params: ModelParams = {
        "iterations": 40,
        "depth": 4,
        "loss_function": "RMSE",
        "random_seed": 42,
        "thread_count": 2,
        "verbose": False,
        "allow_writing_files": False,
    }
    with TemporaryDirectory(prefix="custom-model-demo-") as directory:
        root = Path(directory)
        mlflow.set_tracking_uri(f"sqlite:///{root / 'tracking.db'}")
        experiment = mlflow.create_experiment(
            "custom-model-demo", artifact_location=(root / "artifacts").as_uri()
        )
        mlflow.set_experiment(experiment_id=experiment)
        result = train_model(
            splitter=splitter,
            params=params,
            model_factory=model_factory,
            metric=weighted_mae,
            run_name="scaled-regression",
            config=TrainingConfig(
                tracking=TrackingConfig(log_test_model=False, log_final_model=False)
            ),
        )
        fitted = result.model
        with mlflow.start_run(run_name="serving-parity"):
            logged = fitted.log(partition.train)
        info = logged[1] if isinstance(logged, tuple) else logged
        served = mlflow.pyfunc.load_model(info.model_uri)
        expected = fitted.predict_pool(partition.heldout)
        np.testing.assert_allclose(
            served.predict(
                partition.heldout.to_model_input(categorical_as_strings=True)
            ),
            expected,
        )
        native_predictions = fitted.native_model.predict(
            partition.heldout.to_model_input()
        )
        np.testing.assert_allclose(expected, native_predictions * 1000.0)
        print(
            "native predictions (thousands):", native_predictions[:5].round(4).tolist()
        )
        print("observed rentals:", partition.heldout.y.head(5).to_list())
        print("predicted rentals:", expected[:5].round(1).tolist())
        print(f"validation MAE: {result.validation.mean_metrics['mae']:.3f}")
        assert result.test_metrics is not None
        print(f"test MAE: {result.test_metrics['mae']:.3f}")
        print("serving predictions match: True")

    Pass model_factory to train_model together with your ordinary metric and TrainingConfig. The metric receives predictions after the inverse scale transformation. The same factory is used for feature selection, tuning trials, validation, and the final fresh fit. get_refit_params transfers the selected iteration budget to that last fit; the factory supplies the target scale again.

    Preserve predictions in serving¶

    Logging only the inner CatBoost model would return values in scaled units. The example's log writes the native model plus a concrete JSON settings file, then uses MLflow Models From Code with this separate serving entrypoint:

    Complete serving entrypoint 
    """MLflow Models From Code entrypoint for the target-scaled example."""

from __future__ import annotations

import json
from pathlib import Path
from typing import TypedDict, cast

import catboost
import mlflow
import numpy as np
import pandas as pd
from mlflow.pyfunc.model import PythonModel, PythonModelContext
from numpy.typing import NDArray


class Settings(TypedDict):
    target_scale: float
    feature_names: list[str]
    cat_features: list[str]


class TargetScaledServingModel(PythonModel):
    def load_context(self, context: PythonModelContext) -> None:
        self.settings = cast(
            Settings, json.loads(Path(context.artifacts["settings"]).read_text())
        )
        self.model = catboost.CatBoostRegressor()
        self.model.load_model(context.artifacts["model"])

    def predict(
        self,
        context: PythonModelContext | None,
        model_input: pd.DataFrame,
        params: dict[str, object] | None = None,
    ) -> NDArray[np.float64]:
        """Return original-unit predictions after native categorical preparation.

        Parameters
        ----------
        context : PythonModelContext or None
            MLflow serving context; unused during prediction.
        model_input : pandas.DataFrame
            Fitted feature columns; categorical values are converted to strings.
        params : dict or None, default None
            Unused inference parameters.

        Returns
        -------
        numpy.ndarray
            One original-unit prediction per input row.
        """
        frame = model_input.loc[:, self.settings["feature_names"]].copy()
        for feature in self.settings["cat_features"]:
            frame[feature] = frame[feature].astype("string").fillna("unknown").astype(str)
        return np.asarray(self.model.predict(frame), dtype=np.float64) * self.settings["target_scale"]


mlflow.models.set_model(TargetScaledServingModel())

    The entrypoint restores feature order and categorical conversion, then applies the inverse scale transformation. It depends only on pinned CatBoost, pandas, NumPy, and MLflow packages. An explicit TrackingConfig.conda_env can supply your own serving environment.

    Backend and diagnostic constraints¶

    Training adapters expose a CatBoost or LightGBM backend through native_model; generic scikit-learn estimators do not satisfy this contract. LightGBMServingModel packages an already trained model and does not implement the complete training adapter interface.

    Observed/fitted reports use the adapter's predictions in original units. Native SHAP diagnostics and ShapRanker inspect native_model and see scaled raw outputs in this example. Multiplication by a fixed positive scale preserves relative feature rankings, but raw contributions must be multiplied by the scale before interpreting them as original-unit contributions.

    Before adopting your own adapter, check metadata alignment, finite one-value predictions, fresh factory instances, selected iteration reuse, and serving prediction equality. The reference below lists the full method signatures.
