# Plots

Plotting functions save a figure to a path you choose. Use them directly for
existing predictions, or enable diagnostic reports in training configuration to
generate figures for validation and test.

## Save a precision-recall curve

```python
from pathlib import Path

from ml_toolkit.config import FigureConfig
from ml_toolkit.plots import classification

curve = classification.precision_recall(
    observed=[0, 0, 1, 1],
    probabilities=[0.1, 0.6, 0.7, 0.9],
    save_fig=Path("figures/precision-recall.png"),
    figure=FigureConfig(dpi=150),
)
print(curve[["threshold", "precision", "recall", "f1"]])
```

The call creates the output directory, writes a PNG, closes the figure, and
returns a pandas table for every distinct threshold. With a threshold of `0.6`,
three observations are selected: precision is `2 / 3` and recall is `1.0`.
The table lets you examine the tradeoff without reading values from the image.

## Pick the report

| Question | Module |
| --- | --- |
| How do precision, recall, F1, and calibration behave? | `classification` |
| Where do predictions differ from observations? | `regression` |
| How much outcome is captured at a given exposure share? | `ranking` |
| How are known positives ranked among unlabeled rows? | `pu` |
| Which feature distributions have shifted? | `psi` |
| How does a numerical feature change over time? | `monitoring` |
| Which features contribute most to predictions? | `explainability` |

Use `FigureConfig` for dimensions, DPI, and output format. To have training
produce the figures, configure `reporting.diagnostics`; the
[task recipes](../configuration.md) show the available switches.

## API reference

Import plotting modules from `ml_toolkit.plots`. Functions differ in whether
they return a table; each return contract is listed below.

::: ml_toolkit.plots.classification
    options:
      members: [binary_curves, precision_recall, f1_threshold, calibration]

::: ml_toolkit.plots.regression
    options:
      members: [observed_fitted, observed_fitted_by_level, monthly_observed_fitted]

::: ml_toolkit.plots.ranking
    options:
      members: [gains_curve, lift_curve]

::: ml_toolkit.plots.pu
    options:
      members: [score_distribution, positive_capture]

::: ml_toolkit.plots.psi
    options:
      members: [feature_psi_plot, monthly_psi_level_distribution]

::: ml_toolkit.plots.monitoring
    options:
      members: [monthly_feature_distribution]

::: ml_toolkit.plots.explainability
    options:
      members: [feature_importance, shap_importance, shap_beeswarm, shap_dependence]
